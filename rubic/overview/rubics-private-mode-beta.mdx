Rubic Private Mode integrates privacy providers into Rubic Best Rate Finder, alongside DEXs, bridges, cross-chain providers, intent providers, and deposit-based providers. 

Supported privacy providers include ClearSwap, Houdini Swap, and RocketX, with more to come. Users can compare private and regular routes in one interface and choose a private swap to break the visible onchain link between sending and receiving wallets.

Private routes are also available through Rubic's API, allowing integrators to offer them within their own products.

Open [Rubic Private Mode](https://app.rubic.exchange/?from=ETH&fromChain=ETH&to=USDT&toChain=TRON&amount=0.1&privateOnly=false).

## **Why Privacy Aggregation Matters**

Privacy providers differ in supported networks and tokens, fees, execution time, and technology. Aggregating them expands coverage and lets users compare available routes without checking each provider separately.

For the same transaction, one provider may offer a better price while another completes the swap faster. Users can choose according to their priorities.

## **How Rubic Private Mode Works**

Rubic supports three types of private transactions where available, each designed to break the visible onchain link between sending and receiving wallets:

- **Private Transfer:** Send the same token to another address on the same network.
- **Private Same-Chain Swap:** Exchange one token for another on the same network and deliver it to the receiving wallet.
- **Private Cross-Chain Swap:** Move value to another network, with or without changing the asset.

Rubic checks which privacy providers support the requested networks, tokens, and amount, then returns available routes. The selected provider executes the transaction, separating the deposit from the payout.

## **Rubic Private Mode Beta**

The original beta brought together six solutions with different privacy architectures: Railgun, Zama, Hinkal Protocol, Privacy Cash, Houdini Swap, and ClearSwap.

It remains available as a separate interface for Railgun, Privacy Cash, ClearSwap, and Houdini Swap. Zama and Hinkal Protocol are currently disabled.

Users who need these solutions can access the beta through Rubic's navigation menu.

Open [Private Mode Beta](https://app.rubic.exchange/privacy).

## **Rubic's Privacy Roadmap**

Six months of exploring different solutions and observing usage in the beta helped shape the current Private Mode.

We continue to integrate additional privacy providers, expand network and token coverage, and improve the experience for users and API integrators.
